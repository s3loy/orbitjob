# 配置 Check 与 SLO

Check 将 HTTP 探测调度为容器执行。其记录的结果可以提供服务等级指标（SLI）。
服务等级目标（SLO）评估这些指标，生成错误预算和告警。

## 开始前

使用有效工作区，并取得所需操作的授权。创建 Check、SLI 或 SLO 分别需要
`check:Create`、`sli:Create` 或 `slo:Create`。定义读取、CheckRun 证据、预算、
预算历史和告警具有独立权限。限定分组范围的访问依据实际父 Check 或 SLO 及其
分组；父资源读取授权不隐含所有派生读取。

安装实例必须为 Check 提供执行命名空间，并能够拉取按摘要固定的探测镜像。
工作负载 Pod 必须能够在安装网络策略下访问 HTTP 目标。从本机成功请求不能
证明探测能够访问目标。

## 创建并观察 Check

在 Console 中打开 **Checks**，选择 **New check**。设置名称、`http_health`
配置、调度、超时和重试限制。调度支持 cron 或间隔；间隔至少为 30 秒。配置的
时区必须有效。创建 Check 前，检查 HTTP URL、受支持的方法和预期状态。不要
将凭据放入未受保护的目标 URL 或复制的诊断输出。

创建操作存储配置。Operator 调度探测、记录其容器执行，并根据确认的终态结果
派生 CheckRun。更改探测配置前，检查 CheckRun 结果和底层执行证据。暂停和
恢复分别要求 `check:Pause` 和 `check:Resume`。暂停新检查不会取消可能已经
启动的执行。

只有符合活动执行修订版本条件的计划才能启动。如果到期时间早于该修订版本激活时间，
Operator 跳过未接受的计划，并推进到下一个间隔或 cron 时间，不会重放该跳过
计划。因此，新建或恢复的 Check 可能需要等待下一次符合条件的调度才产生结果。

结果缺失或不可用不能证明目标健康。探测采集、工作负载执行和派生投影可能独立
失败。解释空结果集前，先检查记录的错误和安装实例健康状况。

## 创建 SLI

选择目标 Check 或可执行来源，并根据其结果实际产生的事实配置判定条件。基于
运行的来源使用 `source_uid`，不是显示名称或修订版本 ID。支持的判定条件键为
`status`（`success` 或 `failed`）和 `duration_ms`；数值耗时条件支持
`==`、`!=`、`<`、`<=`、`>` 和 `>=`，阈值必须为有限非负数。延迟 SLI
要求耗时条件。创建可用性或质量 SLI 还要求非空的良好事件条件。

结果聚合为五分钟分桶。调度遵循情况没有专用 SLI 生成方。已产生事实不支持的
判定条件，不能仅因其名称描述了某个目标就建立该目标。

## 创建并查看 SLO

选择同一租户内可访问的 SLI；限定分组范围的调用方还要求相同分组。设置目标和
受支持的评估窗口：滚动、自然月或季度。Scheduler 将快照评估为预算和消耗告警，
不执行探测 Job。

将 `window_duration` 设置为解析后为整秒的 Go 时长，范围为 `1s` 至 `8760h`，
例如 `24h` 或 `720h`。小于一秒或包含不足一秒余量的值会返回 HTTP 400，
错误字段为 `window_duration`。不支持 `d` 后缀；一天使用 `24h` 表示。
有效时长在存储时保留准确值。

使用独立授权读取当前预算、预算历史和告警（`slo:GetBudget`、
`slo:ListBudgets`、`sloalert:Get`、`sloalert:List`）。集合授权必须覆盖完整
查询范围。限制性 Deny 或边界可以拒绝读取，而不是返回静默过滤后的计数。

没有观察到事件的窗口为未评估。非活动来源或过期测量也会产生未评估预算，而不是
健康结果。100% 目标不允许任何错误；观察到错误即耗尽预算。查看预算时，同时
检查总数和评估原因。暂停 SLO 会停止常规评估，同时保留其已存储定义和先前证据。

时长校验仅用于创建，不会改写既存 SLO。若既存 SLO 显示 `0s`，无法从该值恢复
先前被截断的时长。使用 `slo:Pause` 和当前版本暂停该 SLO，保留其定义与历史，
并在复核窗口且确认符合创建要求后创建替代 SLO。暂停或删除既存 SLO 仍按正常
权限和版本要求处理。

## 更改或移除监控资源

API 对需要版本的 Check/SLI/SLO 修改使用乐观版本控制。发送带版本请求前先读取
当前版本。DELETE 请求体携带 [OpenAPI](../../api/openapi.yaml) 声明的所需
版本；只包含 ID 的请求不完整。创建响应丢失后，先检查保留的 Console 操作状态
和集合，再创建替代资源。不要假定可以使用新身份安全重放监控资源创建。

结果投影和去重请参阅[架构](../architecture.md#terminal-recovery-and-slos)；
父资源和集合授权边界请参阅[安全](../../SECURITY.md#monitoring-evidence)。
